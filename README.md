# Yol Haritası — GitHub Pages

1. Bu klasördeki tüm dosyaları GitHub reposunun ana dizinine yükleyin.
2. GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. Birkaç dakika sonra GitHub Pages adresiniz oluşur.

Ana sayfa: index.html
Soru verileri: data.js
1–4. gün: gun-1.html ... gun-4.html

Not: Site altyapısı arama dahil hazırdır. İlerleyen günlerde soru verileri data.js'e eklenerek günler genişletilir.
